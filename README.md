# Coffee with ATG - 3D Cafe Website

A modern, immersive 3D website for a coffee shop. Features a full-screen video background with interactive 3D floating elements (built with Three.js) that react to mouse movement.

## How to Setup Locally
1. Download the video from TikTok (use a watermark remover) or use any cafe video.
2. Rename the video file to `your-video.mp4` (or update the `<source>` tag in `index.html`).
3. Place the video in the same folder as `index.html`.
4. Open `index.html` in your web browser.

## Tech Stack
- HTML5
- CSS3
- JavaScript (Three.js for WebGL 3D rendering)

## Uploading to GitHub
1. Create a new repository on GitHub.
2. Open your terminal in this project folder.
3. Run:
   `git init`
   `git add .`
   `git commit -m "Initial commit"`
   `git branch -M main`
   `git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git`
   `git push -u origin main`
4. To host it live, go to the repository settings -> Pages -> Deploy from branch `main`.
